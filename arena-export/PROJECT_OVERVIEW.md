# 绿玫瑰 · 周末来信

私人中文周末邀请函，以绿玫瑰为主视觉，面向手机及微信浏览器。用户选择时间、活动和备注，结果页汇总并尝试提交回信。保持现有视觉和交互，历史需求文档与后续修改有差异，以当前源码和 ARENA_HANDOFF.md 为准。

技术栈：Vite、原生 TypeScript、CSS，无 React/Vue/Next；Node 本地服务；Cloudflare Workers + SQLite Durable Object 和 FormSubmit。单 HTML 入口，无前端路由框架，步骤由内存状态切换。完整可运行源码和二进制资源在同目录交付压缩包中；本目录 SOURCE_CODE 文件是阅读辅助，不替代原始项目。

详见根目录 ARENA_HANDOFF.md、README.md、CLOUDFLARE.md 和 TESTING.md。原始截图和运行数据不作为项目运行必需内容，不包含在交付包中。
