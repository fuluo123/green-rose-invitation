# 设计与交互规范

默认 C「林间夜色」：深森林绿背景（例如 #153b2d）、浅绿文字和按钮、纸张质感及绿玫瑰柔光。基础设计变量位于 `src/config.ts`、`src/style.css`，覆盖主题位于 `src/themes.css`；以实际 CSS 为准。布局以 430px 左右的手机阅读区为中心，兼顾 320px 窄屏、横屏、桌面、安全区域及自然滚动。

默认标题 C「轻盈诗笺」：中文细衬线，使用本地字体子集并有字体降级；中文自然留白，英文小字为辅助。精细水彩玫瑰和叶片是核心视觉，WebP 加载失败有 SVG 兜底。动画包括首页渐入、低幅呼吸、页面过渡和触控反馈；支持 `prefers-reduced-motion`。

“没空诶”当前按触碰次数依次移动缩淡、变叶片、短暂隐身后重现；实体触碰持续躲避，键盘/辅助技术可触发拒绝。该行为是后续用户选择，和最初需求中有限躲避及可见拒绝入口不同；修改前应先与产品目标对齐。音乐受浏览器自动播放限制，用户手动暂停优先。

主题、标题、躲避方案可通过已有预览参数检查，普通入口默认选定方案。保留选中状态、可见焦点、纯文本呈现用户输入及既有动效；不要把预览方案当成独立页面路由。
